# Requirements Checklist

- [x] One canonical browser entrypoint is defined.
- [x] Admin and Tenant authentication boundaries are separate.
- [x] Browser secret restrictions are explicit.
- [x] Light/dark, responsive, keyboard, loading, empty, denied, locked, and error states are specified.
- [x] Surface inventory covers Admin, Tenant, Local Manager, developer, and evidence domains.
- [x] Legacy Connect and Local Manager compatibility is preserved.
- [x] Mutation preflight, approval, readback, and rollback UX are required.
- [x] Logical Resource API usage is required instead of raw tables.
- [x] Foundation implementation is tested and registered.
- [ ] Admin BFF threat model is approved.
- [ ] Accessibility audit passes WCAG 2.2 AA.
- [ ] Staging and production parity evidence is recorded.
