# Rollout and Recovery

## Stage 0 — Specification

No runtime effect.

## Stage 1 — Internal read-only preview

Enable ECE resolution for Admin diagnostics only. No Tenant export.

## Stage 2 — Tenant shadow

Run composition beside current Tenant GPT behavior without changing visible options. Require zero isolation leaks and zero unexplained new allows.

## Stage 3 — Read-only Tenant cohorts

Promote Brand/resource discovery, analytics, schema discovery, workflow inspection, and device contradiction suppression.

## Stage 4 — Questionnaire cohort

Use schema-driven questions while execution remains preview-only. Monitor clarification, inferred options, stale evidence, and abandonment.

## Stage 5 — Mutation pilots

Promote separately: Brand-scoped grant, WordPress draft, bounded CRM update, workflow run. Direct publish, campaign spend, deployment, device install, destructive operations, and external sends require later decisions.

## Kill switches

Global orchestration, per-capability projection, per-Tenant cohort, questionnaire-only, operation handoff, provider adapter/certification, and grant-pilot flags.

## Rollback

Return visible flow to legacy questionnaire; keep shadow evidence/operations; disable exports/mutation cohorts; retain audit/readback; never automatically replay blocked or ambiguous operations.

## Production verification

Test same provider across two Brands/connections, no-widening grant preview, live WordPress schema, healthy-device suppression, Arabic safe output, support retry, and secret/internal-ID absence.
