# نظرة عامة عربية

تهدف هذه الحزمة إلى إنشاء طبقة عامة قابلة للتكيف للتفويض والموافقات والتنفيذ والتحقق، بدل إضافة مسار ثابت لكل مهارة أو تكامل.

تفصل البنية بين تعريف القدرة، علاقات الفاعل بالمورد، المنحة، قرار السياسة، الموافقة المحددة النطاق، اختيار المنفذ، التنفيذ، القراءة الراجعة، والمصالحة المستمرة.

المهارة النشطة لا تعد معلقة لمجرد أن بعض عملياتها تحتاج موافقة. تعرض الحالة في محاور مستقلة: الإتاحة، التفويض، الموافقة، التنفيذ، والتحقق.

هذه الحزمة تصميمية فقط. لا تلغي بوابات الأمان ولا تنفذ عمليات خارجية ولا تغير الإنتاج قبل المرور بالـshadow mode والاختبارات والمراجعة والإطلاق المتدرج.
