# نظرة عامة عربية

تنشئ هذه الحزمة نموذجًا عامًا وقابلًا للتكيف للتفويض والموافقة والتنفيذ والتحقق، بدل إضافة مسار ثابت لكل مهارة أو مزود.

تفصل البنية بين تعريف القدرة القانونية المستقرة، علاقات الفاعل بالمورد، المنحة الفعالة، قرار السياسة السياقي، الموافقة المحددة بالطلب والمدة، اختيار منفذ معتمد، التنفيذ الآمن، القراءة الراجعة، والمصالحة المستمرة.

المنحة النشطة تظل نشطة حتى عندما تتطلب عملية بعينها موافقة وقت التشغيل. تعرض الإتاحة والتفويض والموافقة والتنفيذ والتحقق كمحاور مستقلة.

الحزمة تصميمية وShadow-first. لا تفعّل كتابة لدى مزود خارجي، ولا تغيّر تفويض الإنتاج، ولا تلغي المسارات الحالية قبل إثبات التكافؤ والإطلاق المتدرج.
