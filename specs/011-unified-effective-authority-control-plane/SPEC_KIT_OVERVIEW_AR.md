# نظرة عربية — طبقة التحكم الموحدة للسلطة الفعّالة

تهدف هذه المواصفة إلى منع تكرار اختلاف الصلاحيات والعدادات بين Activation وTool Catalog وDashboard وConnectors وRuntime.

## القرار

يستخدم Admin وTenant محرك قرار واحد. الاختلاف بينهما يكون في نطاق السلطة الممنوح، وليس في خوارزمية مختلفة أو جداول مختلفة أو استثناءات داخل كل Controller.

تُحسب السلطة الفعّالة من:

`Actor + Subject Scope + Capability + Operation + Resource + Context + Policy + Runtime Readiness`

ثم يصدر المحرك `Effective Authority Manifest` واحدًا، وتشتق منه الأدوات والتبويبات واللوحات والموصلات وأهلية التنفيذ وأسباب المنع.

## مبادئ غير قابلة للتفاوض

1. Admin ليس Tenant بمعرّف صفري.
2. الرؤية لا تعني التنفيذ.
3. الأدوات والواجهات ليست مصدر صلاحية.
4. Actor منفصل عن Subject، خاصة في دعم العملاء والتشخيص الإداري.
5. لا Impersonation ضمني؛ التفويض الإداري صريح ومحدود زمنيًا ومسجل.
6. الغموض بين الموارد أو الاتصالات يمنع التنفيذ ولا يُحل بالتخمين.
7. إبطال العضوية أو المنحة أو الاتصال يبطل القرارات والإسقاطات المتأثرة.
8. التنفيذ يعيد التحقق من البوابات الحرجة في نفس الدورة.
9. SQL هو مصدر الحقيقة الديناميكي، بينما تبقى ثوابت الأمان الجوهرية في الكود.
10. أي اختلاف بين Registered وAuthorized وProjected وExecutable يُسجل كـAuthority Projection Drift.

تشمل الحزمة التصميم، حالات الاستخدام، المخاطر، نموذج البيانات، العقود، خطة الترحيل، اختبارات العزل بين المستأجرين، آلية المصالحة، وضوابط منع التكرار. لا تغيّر هذه الحزمة سلوك الإنتاج بذاتها.
