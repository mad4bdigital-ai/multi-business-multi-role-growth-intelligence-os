# Requirements Checklist

- [ ] Public topology is Git-controlled.
- [ ] Dynamic MCP tools and schemas remain SQL-controlled.
- [ ] Admin and tenant authentication profiles are separate.
- [ ] Real tenant JWT acceptance test exists.
- [ ] Fixed operation membership is canonical.
- [ ] Dynamic membership is principal-aware in SQL.
- [ ] Input and output schemas are versioned and validated.
- [ ] Generator is deterministic and temporary-first.
- [ ] Builder guard rejects null/empty property schemas.
- [ ] Operation budgets include warning headroom.
- [ ] Auto-sync does not auto-merge schema changes.
- [ ] Gateway has no DB/business logic.
- [ ] Gateway policy is generated and signed.
- [ ] Legacy compatibility and rollback are documented.
